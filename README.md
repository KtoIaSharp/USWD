# USWD - Universal Steam Workshop Downloader

### Описание
USWD — программа для скачивания коллекций модов из Steam Workshop через SteamCMD.

### Возможности
- 📦 Скачивание целых коллекций
- 🔧 Скачивание отдельных модов
- 🎮 Поддержка ЛЮБЫХ игр
- 📊 Прогресс-бар с оценкой времени
- 💾 Автосохранение настроек
- 🎨 Настраиваемый цвет интерфейса

---

## Установка

**Вариант 1:** Скачай `USWD.exe` в [Releases](https://github.com/KtoIaSharp/USWD/releases)

**Вариант 2:** Скачай ZIP (исходный код)
