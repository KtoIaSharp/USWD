# 🎮 USWD — Universal Steam Workshop Downloader

**USWD** — консольная утилита для скачивания модов и коллекций из **Steam Workshop**
через **SteamCMD**. Поддерживает любые игры, умеет искать игру по названию, качать
пакетами и автоматически устанавливать моды в папку игры.

> 💡 Работает без входа в Steam-аккаунт — SteamCMD авторизуется анонимно для
> публичных воркшоп-предметов.

---

## ✨ Возможности

| Функция | Описание |
|---|---|
| 📦 Коллекции | Скачивание целых коллекций по одной ссылке |
| 🔧 Один мод | Загрузка отдельного мода по ID |
| 📚 Пакетный режим | Загрузка нескольких коллекций/ID из текстового файла |
| 🔍 Поиск игр | Поиск игры по названию в базе App ID (без API) |
| 🎮 Любые игры | RimWorld, Noita или своя игра по App ID |
| 💿 Автоустановка | Копирование скачанных модов в папку Mods игры |
| 📊 Прогресс | Прогресс-бар с оценкой оставшегося времени |
| 🔇 Режимы вывода | Тихий / Нормальный / Debug |
| 🎨 Интерфейс | Настраиваемый цвет консоли |
| 💾 Настройки | Автосохранение пути SteamCMD, игры и папки Mods |
| 📤 Экспорт/импорт | Сохранение и загрузка списков ID модов |
| 🧾 Логи | Журнал каждой сессии в папке `logs/` |

---

## 📋 Требования

- **Python 3.9+** (для запуска из исходников)
- **SteamCMD** — устанавливается прямо из меню программы (пункт 3)
- Библиотеки `requests` и `beautifulsoup4` — устанавливаются из меню (пункт 8),
  либо вручную:

  ```bash
  pip install -r requirements.txt
  ```

---

## 🚀 Установка

**Вариант 1 — готовый `.exe`:** скачай `USWD.exe` из [Releases](https://github.com/KtoIaSharp/USWD/releases)

**Вариант 2 — из исходников:**

```bash
git clone https://github.com/KtoIaSharp/USWD.git
cd USWD
pip install -r requirements.txt
python USWD.py
```

**Сборка своего `.exe`** (нужен PyInstaller):

```bash
pyinstaller USWD.spec
```

---

## 🕹 Быстрый старт

1. Запусти программу.
2. **Пункт 8** — установи библиотеки (`requests`, `beautifulsoup4`).
3. **Пункт 3 → 1** — установи/укажи SteamCMD.
4. **Пункт 2** — выбери игру (по умолчанию RimWorld, либо найди по названию).
5. **Пункт 1** — скачай коллекцию по URL или отдельный мод по ID.
6. Согласись на **автоустановку** — моды скопируются в папку Mods игры.

Ссылка на коллекцию выглядит так:

```
https://steamcommunity.com/sharedfiles/filedetails/?id=123456789
```

```
USWD/
├── USWD.py                 # Точка входа
├── requirements.txt        # Зависимости
├── USWD.spec               # Конфиг сборки PyInstaller
└── uswd/                   # Пакет с логикой
    ├── cli.py              # Главное меню
    ├── config.py           # Константы и пути
    ├── colors.py           # Цвета интерфейса
    ├── console.py          # Очистка консоли
    ├── output_mode.py      # Режимы вывода
    ├── logger.py           # Логирование
    ├── progress.py         # Прогресс-бар
    ├── settings.py         # Загрузка/сохранение настроек
    ├── catalog.py          # База App ID и поиск игр
    ├── steamcmd.py         # Установка/обновление SteamCMD
    ├── workshop.py         # Скачивание модов и установка в игру

    └── downloader.py       # Сборка приложения
```

## ⚙️ Настройки и файлы

Программа создаёт рядом с собой (в рабочей папке) служебные файлы:

| Файл | Назначение |
|---|---|
| `downloader_settings.txt` | Путь к SteamCMD, папка Mods, выбранная игра |
| `color_settings.txt` | Выбранный цвет интерфейса |
| `output_mode.txt` | Режим вывода |
| `console_settings.txt` | Автоочистка консоли |
| `steam_appid_list.json` | Кэш базы игр (обновляется раз в 7 дней) |
| `logs/` | Логи сессий |
